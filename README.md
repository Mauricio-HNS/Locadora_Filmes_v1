# Film Rental API — ASP.NET Core

A film-rental web application developed as part of an earlier technical assessment.

## Project history

This repository represents an important stage of my C# development: implementing a complete business domain from a defined technical challenge.

Instead of hiding its origin as a job exercise, the repository documents what it demonstrates technically and preserves it as part of my progression.

## What it demonstrates

- ASP.NET Core MVC
- Entity Framework Core
- domain models
- customer and film management
- rental business operations
- controller-based API endpoints
- Swagger / OpenAPI

## Architecture

```text
HTTP
 ↓
Controllers
 ↓
Business / Domain Models
 ↓
Entity Framework Core
 ↓
Application data
```

## Engineering lessons

The project was useful for working with:

- REST-style endpoint design
- entity relationships
- validation
- business workflows
- API documentation
- separation of HTTP concerns from domain behavior

## Historical note

The solution targets .NET 5 and uses Entity Framework Core 5. It is therefore intentionally classified as a legacy project.

Modernization should be performed separately, with tests added before upgrading framework and dependencies.
